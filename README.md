Weather Application 🌤️
A simple weather application built with Python and Tkinter.
Features
• Search for a city by name
• Get geographical coordinates using the Open-Meteo Geocoding API
• Retrieve the current temperature using the Open-Meteo API
• Display weather information in a graphical interface
Technologies
• Python
• Tkinter
• Requests
• Open-Meteo API
